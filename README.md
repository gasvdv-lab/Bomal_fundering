# bomal_fundering v0.7.0 — Full AR Raster Projection
Het opgeslagen raster wordt volledig in AR geprojecteerd. P00 is de oorsprong. Alle actieve punten blijven lokale mm-coördinaten binnen één rigide ProjectRoot. Geen afzonderlijke anchors per punt. De laser blijft de definitieve maatcontrole.
