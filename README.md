# Bomal Fundering v0.7.3 — X Marker / Anchor World-Lock Test

Doel: testen of P00 + tweede referentie + één rigide raster stabieler blijft met WebXR anchors.

## Gebruik
1. Leg de houten X met de kruising exact op P00.
2. Kies P03 of een ander betrouwbaar tweede punt.
3. Start AR en tik P00.
4. Tik daarna exact het fysieke midden van het tweede punt.
5. Het volledige raster verschijnt en blijft één rigide object.
6. Loop weg en terug naar P00 en controleer drift.
7. Gebruik **Herijk** als test om P00 opnieuw te registreren.

De houten X is in deze versie een fysieke richtreferentie, nog geen automatische computer-visionmarker. Dat bouwen we pas als de world-lock-test aantoont dat dit nodig is.

Laser/controlemetingen blijven de definitieve maatvoering.
