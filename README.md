# bomal_fundering v0.6.0 — AR Proof of Concept

## Live app / vaste testlink
https://gasvdv-lab.github.io/Bomal_fundering/

Deze release bouwt rechtstreeks voort op v0.5.0.

Nieuw:
- AR Test-tab.
- WebXR immersive-ar supportcheck.
- WebXR hit-test.
- Plaats P00 en daarna P01 op twee fysieke referenties.
- AR-afstand P00→P01 wordt in millimeter weergegeven.
- Testprotocol voor 1 / 5 / 10 minuten.

## Belangrijk
v0.6.0 is bewust een technische go/no-go-test. De AR-meting vervangt de laser niet.
De volledige 15-punts rasteroverlay wordt pas toegevoegd nadat deze WebXR-test op het doeltoestel betrouwbaar genoeg blijkt.
