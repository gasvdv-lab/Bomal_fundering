# TESTING — v0.7.10.0

2. Plaats P00 exact op zwart middelpunt.
3. Plaats P03 exact op zwart middelpunt.
4. Wacht op `MASTER RASTER GEANKERD`.
5. Controleer OFFSET 0 mm.
6. Controleer P00–P14.
7. Loop een ruime toer en kom terug.
8. Controleer vooral P00, P03 en een ver punt zoals P14.
9. Raster moet als één geheel blijven; geen onderlinge correcties.
10. Test OFFSET ±2 mm: alle punten moeten samen bewegen.
11. Test Undo.
